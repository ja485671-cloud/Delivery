# 美術出圖提示詞（給 ChatGPT 出圖用）

## 怎麼用

**第一輪（現在）：先決定風格。** 用下面三組提示詞，各畫一張「天璣老人」，比較後選一種風格（或混搭）。
**第二輪：風格定了之後**，同一種風格做五位老師的定裝圖 → 表情 → 嘴型 → 房間背景 → 大廳。第二輪的提示詞等風格定了我再給你，會依你選的風格調整。

### 讓角色長得一致的訣竅
1. **同一位老師的所有圖，都在同一個 ChatGPT 對話裡出**，而且每次都附上第一張定裝圖，說「以這張為準」。
2. 先出一張**定裝圖**（正面半身、表情平靜、嘴巴閉著），之後的表情和嘴型都從這張改。
3. 改嘴型時，用 ChatGPT 的**「選取區域編輯」**，只框嘴巴，其他地方才不會跑掉。
4. 角色一律**透明背景或純綠色背景（#00FF00）**，背景和角色分開出，我才能在網頁上疊圖、做動畫。

### 圖片規格
| 用途 | 尺寸／比例 | 背景 |
|---|---|---|
| 老師立繪（半身） | 1024×1536（直式 2:3） | 透明或純綠 |
| 表情、嘴型 | 跟立繪完全同尺寸、同構圖 | 同上 |
| 房間背景 | 1536×1024（橫式），手機會裁切中間 | 完整背景，畫面中間留空給老師站 |
| 大廳 | 1536×1024 | 完整背景 |

存檔命名放進 `content/teachers/<老師>/images/`：`base.png`、`expr_<表情>.png`、`mouth_<嘴型>.png`、`room.png`。

### 選風格時可以看的重點
- **縮到手機大小還好不好看**：把圖縮到大約 300 像素寬再看一次。
- **嘴巴好不好改**：嘴巴越清楚（不被鬍子完全蓋住），口型動畫越明顯。天璣老人有長鬍子，要特別注意嘴巴有沒有露出來。
- **五位老師放在一起協調嗎**：塔羅露娜是西洋風，要確認選的風格也能畫出她。
