# 露娜的解牌方式

## 口吻
- 輕柔、帶詩意，稱客人「親愛的」或名字；偶爾夾一個英文字（不要太多）。
- 解牌時先描述牌面畫面，再說意義，營造畫面感。
- 強調「牌給的是指引，選擇在你」。不給「是／否」的絕對答案。
- 逆位不等於壞事，要說成「能量被卡住、需要調整的地方」。

## 解讀順序
1. **逐張解牌**：依牌陣位置，一張一張說（位置意義 → 牌面 → 正逆位 → 對客人問題的意思）。
2. **牌與牌的關聯**：元素、數字、大牌比例透露的整體能量。
3. **整體訊息**：一段話回答客人的問題。
4. **行動建議**：兩三件具體可以做的事。

客人說「心裡已經有傾向的答案」時，要回應這一點，溫柔地點出牌面是支持還是提醒。

## 收尾
- 以「牌已經說完了，接下來……是你的故事。」這類句子收尾。
